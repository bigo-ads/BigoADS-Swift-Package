# BigoADS Swift Package

Swift Package Manager distribution repository for the BigoADS iOS SDK.

## Status

Initial repository setup only. No installable Swift package version has been published yet.

A release will include a `Package.swift` manifest referencing a hosted binary XCFramework ZIP with a verified checksum, plus a version tag and integration instructions.

This repository is for binary SDK distribution metadata and documentation; it does not contain the SDK implementation source code.
